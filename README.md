# 야생 플러스 (Wild Plus)

마인크래프트 **Java 26.3 · NeoForge** 모드. 야생을 조금 더 재미있게 만들어 줍니다.

## 설치 (CurseForge)

1. CurseForge에서 **Minecraft 26.3 + NeoForge** 프로필을 만든다 (Create Custom Profile → 버전 26.3, 모드 로더 NeoForge).
2. 이 저장소의 **Releases → latest** 에서 `wildplus-1.3.1.jar` 를 받는다.
3. 프로필의 `…` 메뉴 → **Open Folder** → `mods` 폴더에 jar를 넣고 실행.

## 기능

### 🌕 블러드문
- 밤이 시작될 때 12% 확률로 발생 (월드 생성 후 3일간은 없음)
- 화면 위 붉은 보스바로 남은 시간 표시, 하늘이 어둡고 안개가 짙어짐
- 10초마다 플레이어 주변에 몬스터가 추가로 출몰하고, 새로 나타난 몬스터는 **힘·신속** 버프
- 처치 시 30% 확률로 **핏빛 파편**, 경험치 2배
- 블러드문 밤에는 **잠을 잘 수 없음**

### ⭐ 정예 몹
- 자연 스폰된 몬스터 5%가 정예 몹 (블러드문 중 15%)
- 금색 이름표, 체력 2배, 공격력 +50%, 방어력 +4, 넉백 저항
- 처치 시 핏빛 파편 1~3개 + 금·다이아몬드·귀환의 두루마리·행운의 부적 확률, 경험치 3배

### ⚔ 핏빛 강철 장비
| 아이템 | 제작 |
|---|---|
| 핏빛 강철 주괴 | 철 주괴 1 + 핏빛 파편 4 (모양 없이) |
| 검·곡괭이·도끼·삽 | 철 도구와 같은 모양 (주괴 + 막대기) |
| 투구·흉갑·레깅스·부츠 | 철 갑옷과 같은 모양 |

- 성능: 철과 다이아몬드 사이 (다이아몬드 블록까지 채굴 가능, 인챈트가 잘 붙음)
- **검**: 흡혈 — 입힌 피해의 20%만큼 회복
- **갑옷 4부위 세트**: 밤에 몬스터에게 받는 피해 15% 감소

### 🗺 탐험 보물
던전·폐광·난파선·폐허 포털·전초기지 등 상자에는 일반 보물, 사막·정글 사원·매장된 보물·저택·고대 도시·요새·보루·엔드 시티 상자에는 희귀 보물이 추가로 들어갑니다.
- **귀환의 두루마리**: 3초간 읽으면 침대(없으면 월드 스폰)로 순간이동. 종이 + 엔더 진주 + 핏빛 파편 2로도 제작 가능
- **행운의 부적**: 인벤토리에 있으면 행운 효과 (아주 희귀)
- **여행자의 도시락**: 배고픔 8 + 신속 1분. 빵 + 익힌 고기·생선 + 말린 켈프 + 사과 → 2개

### 🌶 고추 농사와 요리
- **고추 씨앗**: 잔디·큰 잔디·고사리를 부수면 8% 확률로 획득 (고추 1개로 씨앗 2개 제작 가능)
- 밭에 심으면 밀처럼 자람, 다 자라면 고추 1~3개
| 음식 | 만드는 법 | 효과 |
|---|---|---|
| 고추 | 수확 | 화염 저항 20초 |
| 얼큰한 스튜 | 그릇 + 고추 2 + 구운 감자 + 당근 | 배고픔 10, 힘·화염 저항 90초 |
| 꿀 토스트 | 빵 + 꿀 병 | 재생 8초 |
| 생고기 꼬치 (2개) | 막대기 2 + 날고기(소·돼지·양·닭·토끼) + 고추 | — |
| 매콤 꼬치구이 | 생고기 꼬치를 화로·훈연기·모닥불에 굽기 | 배고픔 9, 성급함 1분 |

### ⛏ 새 광석과 도구 (2차)
| 광석 | 높이 | 얻는 것 |
|---|---|---|
| 미스릴 광석 (심층암 포함) | Y -48 ~ 32 (Y -8 근처에 가장 많음) | 미스릴 원석 → 화로·용광로 → **미스릴 주괴** |
| 비취 광석 (심층암 포함) | Y -16 ~ 96 고르게 | **비취** (경험치 많이 줌) |

- 철 곡괭이 이상으로 캐야 하고, 행운·섬세한 손길 인챈트가 적용됩니다.
- **미스릴 도구** (검·곡괭이·도끼·삽·괭이): 채굴 속도가 다이아몬드보다 빠르고(10), 내구도 1300, 인챈트가 잘 붙음. 철 도구와 같은 모양으로 제작.
- **미스릴 괭이**: 우클릭 한 번에 **3x3 경작** (웅크리면 한 칸).
- 미스릴 블록·비취 블록 (9개 압축).

### 🎣 낚시 시스템 (2차)
물고기를 낚으면 일정 확률로 새 어종으로 바뀝니다. **어디서·언제** 낚느냐에 따라 나오는 물고기가 달라요.

| 물고기 | 조건 | 먹으면 |
|---|---|---|
| 무지개송어 | 강 (특히 낮), 낮이면 어디서나 | 구워 먹기 (배고픔 7) |
| 달빛 물고기 | 밤 | 야간 투시 3분 |
| 폭풍 장어 | 비 (뇌우 때 더 잘) | 신속 / 장어구이: 신속 2분 |
| 심해 아귀 | 바다 (밤에 더 잘) | 수중 호흡 3분 |
| 얼음 빙어 | 추운 지역 | 화염 저항 1분 |
| 황금 잉어 | 어디서나 아주 드물게 | 흡수 II 2분 + 재생 II |

- **침몰한 보물상자**: 탁 트인 물에서 2% 확률. 우클릭하면 금·비취·미스릴·다이아몬드·인챈트 책·바다의 심장 등이 나옵니다.
- **비취 낚싯대** (낚싯대 + 비취 2 + 미스릴 주괴): 새 어종·보물상자 확률 2배, 20% 확률로 두 마리, 내구도 512. 바닐라 낚싯대 인챈트(미끼·바다의 행운) 사용 가능.
- 요리: **모둠회** (그릇 + 생선 2) 수중 호흡·행운 / **매운탕** (그릇 + 생선 + 고추 + 토마토) 배고픔 12, 힘·재생

### 🌱 농사 시스템 (2차)
- **토마토** (씨앗은 잔디에서), **딸기** (열매를 바로 심음) 추가. 잔디를 부수면 고추·토마토·딸기 씨앗이 나와요.
- **스프링클러** (비취 + 미스릴 주괴 3 + 물 양동이): 2초마다 주변 9x9를 적셔서 경작지가 마르지 않고, **작물이 3~4배 빨리 자랍니다**.
- **비료** (뼛가루 2 + 썩은 살점/씨앗/켈프/흙 → 2개): 클릭한 곳 주변 3x3 작물·묘목에 뼛가루 2번 효과.
- 요리: **토마토 수프** (그릇 + 토마토 3), **피자 조각** 3개 (밀 2 + 토마토 + 익힌 고기나 버섯), **딸기 타르트** 2개 (밀 + 딸기 2 + 설탕 + 달걀)
- 던전·폐광·마을 집·사원 등 상자에 미스릴 원석·비취·새 씨앗·비료가 추가로 들어갑니다.

### 💰 화폐 시스템 (3차)
| 동전 | 가치 | 얻는 곳 |
|---|---|---|
| 동화 | 1동 | 몬스터 처치(35%, 블러드문엔 60%), 황금 슬라임, 상인에게 판매 |
| 은화 | 10동 | 정예 몹, 도적, 상자 보물, 상인에게 판매 |
| 금화 | 100동 | 정예 몹(25%), 도적 야영지, 큰 황금 슬라임, 황금 잉어 판매 |

- **환전**: 은화 1 → 동화 10, 금화 1 → 은화 10 (제작대). 위로 바꿀 땐 **동전 주머니**를 쓰세요.
- **동전 주머니** (가죽 3 + 실): 우클릭하면 가방의 동전을 모두 넣고, 웅크리고 우클릭하면 가장 적은 개수로 꺼냅니다(자동 환전). 툴팁에 잔액 표시. 자판기는 주머니 잔액으로도 결제돼요.

### 🧑‍🌾 상인과 거래 (3차)
**교역소**에 상주하는 두 상인과 동전으로 거래합니다(바닐라 거래 화면). 사라지지 않고, 하루마다 재입고돼요.
- **잡화 상인**: 밀·당근·감자·토마토·딸기·고추·물고기를 사 주고(황금 잉어는 금화 1!), 씨앗·비료·귀환의 두루마리·스프링클러·비취 낚싯대·동전 주머니·자판기·행운의 부적 등을 팝니다.
- **대장장이 상인**: 석탄·철·금·레드스톤·청금석·미스릴 원석·비취·핏빛 파편·다이아몬드를 사 주고, 미스릴 주괴·미스릴/핏빛 강철 장비·모루·경험치 병 등을 팝니다.
- 두 상인 모두 에메랄드 ↔ 은화 교환 가능 (바닐라 주민 거래와 연결).

### 🏧 동전 자판기 (4차에서 새로 바뀜)
**실물 크기(2칸 높이)** 자판기입니다. 문처럼 설치하면 위로 한 칸을 더 차지하고(위에 빈칸이 있어야 설치됨), 높은 유리창 안 **3단 선반에 상품 9칸이 진열**됩니다. 위·아래 어느 칸을 우클릭해도 자판기 화면이 열립니다.
피스톤으로 위 칸을 밀어도 본체는 남고 위 칸은 곧 다시 채워져서, 남의 자판기나 야생 자판기를 털 수 없어요. 예전 1칸짜리 자판기는 위에 빈칸이 있으면 자동으로 2칸이 됩니다.

**사는 법 (누구나)**
1. 동전을 **투입구** 칸에 넣거나 **[동전 넣기]** 버튼(가방의 동전·주머니 잔액을 모두 투입)
2. 원하는 상품 아래 **가격 버튼**을 누르면 **꺼내는 곳**으로 상품이 나옴 (꺼내는 곳이 차 있으면 자판기 앞으로 떨어짐)
3. **[반환]** 또는 화면을 닫으면 남은 돈이 돌아옴 (주머니가 있으면 주머니로)

**파는 법 (자판기를 직접 설치한 사람만)**
- 진열 칸 9개에 상품을 직접 넣고 뺄 수 있어요 (칸마다 한 묶음 = 재고).
- **[관리]** → 가격 버튼을 눌러 칸 선택 → **+1 / +10 / +100 / -1 / -10 / -100** 으로 가격 조정 → **[완료]**
- 팔린 돈은 자판기에 쌓이고 **[수익 N동]** 버튼으로 회수.
- 설치한 사람만 부술 수 있고, 부수면 재고와 수익이 나와요.

**남의 자판기 · 야생 자판기**: 상품과 가격을 바꿀 수 없고 정해진 대로만 이용할 수 있어요. 교역소의 자판기는 주인이 없는 **무한 재고** 자판기예요(음식 9종 / 생활용품 9종).

### 🎰 뽑기 기계 (4차)
우클릭 한 번에 **10동**(설정 가능)을 내고 캡슐 하나를 뽑아요. 동전·씨앗·음식·에메랄드·비취·귀환의 두루마리·미스릴·다이아몬드·자석 부적… 그리고 **대박**(금화, 황금 잉어, 행운의 부적, 마법이 부여된 황금 사과)이 나오면 폭죽 소리와 함께 주변 모두에게 알려져요. 교역소에도 한 대 있습니다.
제작: 유리 3 + 철 주괴 4 + 레드스톤 + 동화

### 🧰 편의 기능 (4차)
| 기능 | 사용법 |
|---|---|
| **나무 한 번에 베기** | 웅크린 채 도끼로 원목을 캐면 이어진 나무 전체가 베어짐 (최대 128개, 도구가 부서지기 직전엔 멈춤) |
| **광맥 한 번에 캐기** | 웅크린 채 곡괭이로 광석을 캐면 붙어 있는 같은 광석 전체 (최대 48개) |
| **우클릭 수확** | 다 자란 작물을 우클릭하면 수확 + 자동으로 다시 심음 (밀·당근·감자·비트·고추·토마토·딸기 등) |
| **무덤** | 죽으면 아이템이 그 자리의 무덤에 보관되고 좌표가 채팅에 표시됨. 우클릭하면 전부 돌려받음. 무덤은 주인만 부술 수 있음 |
| **사망 위치 안내** | 죽으면 좌표와 차원을 채팅으로 알려줌 |
| **정보 HUD** | 화면 왼쪽 위에 `N일차 · 오후 3:20` 과 좌표·방향 표시 (끄기 가능) |
| **자석 부적** | 가지고 있으면 주변 8칸의 아이템·경험치를 끌어옴. 우클릭으로 켜기/끄기, 웅크리면 잠시 멈춤. 제작: 철 주괴 3 + 레드스톤 2 + 미스릴 주괴 2 |
| **휴대용 제작대** | 우클릭하면 어디서나 제작대. 제작: 제작대 + 가죽 + 실 |
| **휴대용 엔더 상자** | 우클릭하면 어디서나 엔더 상자. 제작: 엔더 상자 + 가죽 + 실 + 비취 |

모든 편의 기능은 설정에서 끌 수 있어요 (`나무 베기`, `광맥 캐기`, `우클릭 수확`, `무덤`, `HUD`).

### 🏕 새 구조물 (3차)
- **교역소**: 들판·숲·사바나·타이가·사막·벚나무 숲 등에 생김. 줄무늬 천막 가판대, 두 상인, 무한 재고 자판기 2대, 뽑기 기계, 보급품 상자.
- **도적 야영지**: 숲·들판·타이가·사바나·악지에 생김. 모닥불과 천막 셋, 도적 셋, **약탈품 상자**(동전·에메랄드·철·금·귀환의 두루마리…).
- 던전·사원·보물·마을 집 상자에도 동전이 들어갑니다.

## 설정
모드 목록 → 야생 플러스 → **설정** 버튼에서 바꿀 수 있어요.
- `config/wildplus-synced.toml` (월드 공통): 블러드문 확률·유예 일수·추가 출몰 수, 정예 몹 확률, 편의 기능 켜기/끄기, 뽑기 가격
- `config/wildplus-client.toml` (내 화면): 정보 HUD, HUD 좌표 표시

## 명령어 (치트 허용 시)
- `/wildplus bloodmoon start` — 블러드문 바로 시작
- `/wildplus bloodmoon stop` — 블러드문 종료

## 개발
- 코드 수정 후 `main` 에 푸시하면 GitHub Actions가 빌드·서버 테스트를 거쳐 Releases의 `latest` 를 갱신합니다.
- 텍스처: `python3 tools/gen_textures.py`, 데이터(JSON): `python3 tools/gen_data.py`
